# Security policy

ReelPilot sends mouse input to a running game. Input that remains held after pause, stop,
failure, or helper disconnect is a security and safety defect.

Please report input-safety vulnerabilities privately through GitHub's security advisory
feature. Include the ReelPilot version, Windows version, state shown in the dashboard, and
the relevant local log excerpt. Do not attach gameplay recordings until requested because
they may contain private screen content.

F8 is the global emergency stop. ReelPilot does not require administrator privileges and
should not be run elevated.
